# Personal Developer Portfolio

A minimalist and responsive personal portfolio website built using Plain PHP, HTML, CSS, and JavaScript.

## Project Overview

This project showcases my professional experience, technical skills, selected professional contributions, and continuous learning as a growing web developer.

## Project Objectives

- Establish a professional online presence.
- Apply fundamental PHP development concepts.
- Implement modular and maintainable architecture.
- Develop a responsive and accessible user interface.
- Apply web security and performance best practices.

## Technologies Used

- PHP
- HTML5
- CSS3
- JavaScript
- Lucide Icons
- Apache
- XAMPP

## Features

- Minimalist Bento Grid layout
- Responsive design
- Light and dark mode
- Professional experience timeline
- Technology stack
- Professional work showcase
- Scroll reveal animations
- SEO metadata
- HTTP security headers

## System Architecture

The website follows a modular, server-rendered architecture with reusable PHP components, centralized configuration, and separate presentation and behavior layers.

## Local Installation

1. Install XAMPP.
2. Place the project inside the htdocs directory.
3. Start the Apache web server.
4. Open http://localhost/portfolio/.

## Database Requirements

This project does not require a database.
